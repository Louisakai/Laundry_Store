# WORKLOG — Laundry Mobile (2026-08-03)

Tổng kết toàn bộ công việc trong ngày dành cho app Android **laundry-mobile** (Expo SDK 57, React Native 0.86, NativeWind 4, expo-router).

## 1. Sửa lỗi nút bấm không hoạt động (root cause)

**Triệu chứng:** Mọi nút dùng component `Button` (Đăng nhập, Tạo đơn, Thêm địa chỉ, Tối ưu tuyến…) không kích hoạt `onPress` trên Android (cả dev lẫn release).

**Điều tra:**
- Dùng dev-client + Metro, thêm debug `pressCount` state + `console.log` + fetch probe tới `/__probe/login-handler` trong `login.tsx`.
- Kết quả: `pressCount` luôn = 0, backend không nhận probe → handler KHÔNG được gọi.
- Thay nút login bằng `Pressable` trực tiếp → đăng nhập chạy bình thường → xác nhận lỗi nằm trong wrapper `Button`.

**Fix** (`src/components/ui/button.tsx`):
- Bỏ hẳn inner `<View>` wrapper, bỏ prop `style`, bỏ shadow class.
- Dùng single `Pressable` với `accessibilityRole="button"`, `onPress={isDisabled ? undefined : onPress}`, `disabled={isDisabled}`.
- Giữ nguyên API `title` / `variant` / `loading` / `disabled` / `className` / `textClassName`.

## 2. Fix crash native "Requested job cannot be persisted"

**Triệu chứng:** App văng ra sau ~5 giây khi chạy (shipper bật theo dõi vị trí).

**Nguyên nhân:** `expo-task-manager` + `expo-location` đặt background job bền vững (persisted) cho location task nhưng AndroidManifest thiếu quyền `RECEIVE_BOOT_COMPLETED` → `JobScheduler` từ chối → native crash:
```
java.lang.IllegalArgumentException: Requested job cannot be persisted
without holding android.permission.RECEIVE_BOOT_COMPLETED permission
```

**Fix** (`app.json`): thêm `android.permission.RECEIVE_BOOT_COMPLETED` vào danh sách `android.permissions`. Thay đổi **native** → phải rebuild APK (dev-client).

## 6. Wizard "Tạo đơn mới" (`orders/new.tsx`)

### 6.1 Fix StepIndicator chữ dọc
- **Triệu chứng:** nhãn "Loại đơn" hiển thị theo từng chữ dọc (`L\no\nạ\ni\nđ\nơ\nn`).
- **Nguyên nhân:** đường nối `w-full -mx-1` đặt trong cùng `flex-row` với label → ép chiều rộng mỗi ô về ~0 → chữ ngắt từng kí tự.
- **Fix:** tách 2 hàng riêng — hàng chấm số (kèm line nền absolute) + hàng nhãn, mỗi nhãn trong cột `flex-1` với `min-h` và `text-center`.

### 6.2 Chọn ngày tùy ý + giờ cụ thể (mô phỏng web `PresetTimePicker`)
- **Ngày:** chip "Hôm nay" / "Ngày mai" / "Chọn ngày khác" → mở thanh cuộn ngang **60 ngày** kèm thứ + ngày/tháng (dùng `dayOptionLabel`).
- **Giờ:** presets Sáng (8–11h), Trưa (11–14h), Chiều (14–17h), Tối (17–20h) + **"Giờ cụ thể"**: chọn giờ bắt đầu 8:00–21:00, tự tính kết thúc `min(h+3, 22)`.
- Refactor state: bỏ `pickupSlot/deliverySlot` (index), chuyển sang `pickupRange/deliveryRange: [startHour, endHour]`; payload build ISO từ offset ngày + giờ.

### 6.3 Ràng buộc thời gian (giống web)
- Không chọn slot/giờ **đã qua** hôm nay (slot kết thúc ≤ hiện tại bị mờ + khoá).
- Giờ mở cửa 8h–22h (khung kết thúc ≤ 22:00).
- **Giao đồ ≥ nhận đồ + 6h**: `deliveryMinTs = (pickupDate + pickupEnd):00 + 6h`; mọi ngày/giờ giao trước mốc này bị khoá (ngày thiếu toàn bộ slot cũng khoá).

### 6.4 Prefill thông tin liên hệ
- Tên + SĐT của "Người nhận đồ" và "Người giao nhận" mặc định điền `user.fullName` + `user.phone`.
